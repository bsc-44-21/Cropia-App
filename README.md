# Cropia App

Cropia is a smart farming companion application tailored specifically to support farmers. 

**Current Focus:**
At this stage of development and testing, Cropia is primarily focused on supporting the management, detection, and learning resources for **Tomato** and **Maize** crops. All default data, AI features, and disease detection workflows are centered around maximizing the yield and health of these two essential crops.

## Getting Started

This project is a starting point for a Flutter application.
Run `flutter pub get` to install dependencies and `flutter run` to launch the app.
